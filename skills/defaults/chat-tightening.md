---
name: chat-tightening
description: Shorter, clearer answers - lead with the result, cut filler.
triggers: [shorter, be brief, too long, tldr, summarize, keep it short, simple answer]
---
Make the answer as short as it can be while staying complete and correct.

- Lead with the result or the direct answer in the first sentence.
- Match length to the question: a simple question gets one or two sentences.
- Cut filler, restated questions, apologies and generic advice.
- Use a short list only when there are several separate items or steps.
- Keep exact names, numbers, times and identifiers; never drop a caveat that
  changes what the user should do.
- If something is unknown or failed, say so plainly in one line.
