---
name: itsm-gap-finder
description: Find gaps in an IT service process against ITIL practice and say what to fix first.
triggers: [gap analysis, find gaps, itsm gaps, process gaps, itil gaps, service gaps]
---
When asked to find gaps in an IT service process:

1. Restate the process in a few steps, using only what the user and the
   evidence in this request say. Mark anything assumed.
2. Check it against the relevant ITIL 4 practices: incident, problem, change
   enablement, service request, knowledge, service level, monitoring and
   event, configuration, access (identity), and continuity.
3. For each gap give: what is missing, the risk it creates, a concrete fix
   and who would usually own it.
4. Rank the gaps by risk to users and the business, highest first. Keep the
   list short; group small items.
5. Separate observed gaps (backed by data in this request) from likely gaps
   (common in similar setups). Never present a likely gap as observed.
6. End with the first one or two actions that close the biggest risk.
